# M1 Task — Feature Contract and Data Tooling

## Goal

Lock a versioned hand-feature contract that future recognition work can trust, prove
Python and Kotlin produce the same vector, and add research capture, extraction,
manifest, audit and deletion tooling.

## Allowed change surface

`research/`, `contracts/`, `docs/`, `scripts/`, `.github/`, `android/app` (feature
implementation and tests only), `README.md`, `.gitignore`, `AGENTS.md` only if a
rule changes. No new Gradle module.

## Invariants

- `features-v1` is immutable once locked.
- No recognition, LiteRT, GRU/CNN, vocabulary, lessons, Room, DataStore, cloud,
  analytics, pose or face work.
- MediaPipe types stay inside `perception/`.
- Never mirror the inference frame; mirroring is display-only.
- Missing hands and landmarks are explicit masks, never valid zero poses.
- Golden vectors are generated, never hand-edited.
- No raw video stored or committed.
- Consent is required before recording.
- Hardware and dataset gates are `NOT VERIFIED` when not exercised.

## Acceptance gates

| Gate | Evidence |
|---|---|
| G1 | Contract JSON, schema and semantic tests |
| G2 | Python reference tests |
| G3 | Deterministic golden vectors and replay |
| G4 | Kotlin parity tests |
| G5 | Full Android unit suite and debug APK |
| G6 | Regeneration drift check |
| G7 | Manifest, audit and deletion tests |
| G8 | Consent, licence and missingness rejection tests |
| G9 | CI workflow and local `scripts/verify.sh` |
| G10 | Webcam recorder on a real camera |
| G11 | Dataset extraction on a licensed local dataset |
| G12 | Live app wiring (deferred to M2) |

## Commands

```bash
cd research
uv sync --frozen --extra test
uv run --frozen pytest

cd ..
bash scripts/verify.sh
```

## Out of scope

Any model, classifier, lesson, persistence layer, network call or new module.
